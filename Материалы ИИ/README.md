## Где команда поправила ИИ
- Частоты 5 из 33 маршрутов — исправлены по Яндекс Расписаниям.
- «Хабу нужно 8–12 самолётов» — не подтвердилось: хаб в Екатеринбурге держится на ~4–5 SSJ-100.
- Стоимость блок-часа SSJ-100: 380 тыс. ₽ у Gemini → ~600 тыс. ₽ по отчётности «Азимута».
- Налёт 8 ч/сут → факт Red Wings 6,3 ч/сут.
- Загрузка 90,3% (группа «Аэрофлот») → 83% (расчёт по Red Wings 2025).
- «Падение перевозок на 30%» — разница в базе учёта (без чартеров B777).
- Ссылка на файл Росстата битая (404) → население из данных Росстата на 01.01.2025.
- Gemini выдал выдуманные ссылки и рейсы по новым городам — партия отброшена, данные собраны заново с табло (файл 6).
- Модель завышала спрос на парах без рейсов: нашли по истории трёх неудачных запусков 2021–2023 (Челябинск–Уфа, –Самара, –Тюмень), ввели поправку ×0,3 (файл 7).
- Ошибка в коде модели (Claude): расстояние до соседнего аэропорта считалось по прямой, через горы — давало ложный плюс хабу в Волгограде; нашли стресс-тестом, исправили (файл 4).
- Закрытия аэропорта хаба в базовом расчёте были 0% — подставили факт по городам; хаб в Уфе проверили без маршрутов Utair (файл 4).
