## Где команда поправила ИИ
- Частоты 5 из 33 маршрутов — исправлены по Яндекс Расписаниям.
- «Хабу нужно 8–12 самолётов» — не подтвердилось: хаб в Екатеринбурге держится на ~4–5 SSJ-100.
- Стоимость блок-часа SSJ-100: 380 тыс. ₽ у Gemini → ~600 тыс. ₽ по отчётности «Азимута».
- Налёт 8 ч/сут → факт Red Wings 6,3 ч/сут.
- Загрузка 90,3% (группа «Аэрофлот») → 83% (расчёт по Red Wings 2025).
- «Падение перевозок на 30%» — разница в базе учёта (без чартеров B777).
- Ссылка на файл Росстата битая (404) → население из данных Росстата на 01.01.2025.
