# Две проверки модели по данным репозитория (10.11.2026)

Считал Claude по файлам репозитория, цены — со страниц Яндекс Расписаний 10.11.2026. Семён.

## 1. Точность спроса: по парам и по аэропортам

Источник: results/demand_calibration.csv (179 пар с фактическими рейсами; прогноз на отложенных парах).

| Уровень | Показатель | Значение |
|---|---|---|
| Пары городов (179) | R² по логарифмам | 0,39 |
| | корреляция Пирсона / ранговая (Спирмен) | 0,68 / 0,58 |
| | доля пар с ошибкой не больше 2 раз | 59% |
| Аэропорты (37; сумма потоков всех пар аэропорта) | R² по логарифмам | 0,88 |
| | корреляция Пирсона / ранговая | 0,97 / 0,96 |
| | медианная ошибка | 28% |

Как читать: на отдельной паре модель ошибается сильно, но ошибки разного знака гасятся — суммарный поток аэропорта модель передаёт с ошибкой ~30% и почти не путает порядок аэропортов. Оговорка: масса города в модели — пассажиропоток аэропорта, поэтому хорошее совпадение по аэропортам отчасти заложено построением; это довод «ошибки не систематические», а не «модель точна».

Что это значит и чего не значит:

- Это минимальная цена в ноябре (низкий сезон), а тариф модели — минимум августа (пик). Средняя выручка на пассажира за год выше минимальной цены: по РСБУ «Азимута» — 11,9 тыс. ₽ (research/revenue_per_passenger.md). Поэтому базовую доходность 1,15 таблица не опровергает.
- Часть маршрутов (Омск, Оренбург, Томск, Нижний Новгород из Екатеринбурга) — субсидируемые в октябре–декабре: цена билета там снижена, а субсидию модель считает отдельно.
- Но в пользу порога «+45%» таблица не говорит: текущие цены Red Wings ниже тарифа модели на всех 9 маршрутах. Формулировать порог как «если средняя выручка на пассажира окажется на уровне…» и просить у экспертов фактическую цифру.
- **Форма зависимости от расстояния.** Прямая по 9 ценам Red Wings: ≈ 4 100 + 2,8·км ₽ (модель: 7 390 + 3,94·км). Отношение двух линий почти не зависит от расстояния: 0,59 на 400 км и 0,63 на 1500 км. То есть расхождение — в общем уровне (сезон, минимум против средней), а не в форме формулы; менять формулу тарифа по этим данным не нужно.
- **Короткие пары.** Две самые короткие точки лежат ниже линии (0,46): Уфа–Екатеринбург, где цену сбивает Utair (3 827 ₽), и Самара–Нижний Новгород. Это две точки за один день — не доказательство, но повод для проверки устойчивости: тариф на парах короче 550 км −25% (на парах с Utair — на его уровне) и посмотреть, остаются ли короткие спицы в сети и остаётся ли Уфа лучшим хабом.
