Расчёт: гравитационная модель спроса по табло 40 аэропортов (все перевозчики) + логит-модель выбора пассажира + жадный алгоритм размещения бортов по прибыли на блок-час; учтены загрузка, перегоны, база хаба, закрытия аэропорта, субсидии.
