Расчёт: гравитационная модель спроса по табло 40 аэропортов (все перевозчики) + логит-модель выбора пассажира + жадный алгоритм размещения бортов по прибыли на блок-час; учтены загрузка, перегоны, база хаба (118 млн ₽/год), фактические закрытия аэропорта хаба, субсидии; спрос на парах без рейсов ×0,3 (по трём неудачным запускам 2021–2023). Гибрид — хаб в Уфе плюс прямые рейсы из Екатеринбурга и других городов. Модель передаёт порядок величины (корреляция с фактом 0,52), поэтому сравнивайте варианты и пороги, а не точное число пассажиров. Код и данные: github.com/AndreyV105105105/Puhososy.
