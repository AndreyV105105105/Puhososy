# Раздел «Метод» для паспорта (текст для вставки)

**Как считали.** Модель — цепочка из четырёх шагов на Python, все допущения в одном файле параметров, расчёт повторяется одной командой (`python model/run_all.py`, код и данные — в репозитории).

1. **Спрос между городами — гравитационная модель** (стандарт транспортного планирования):
   T_ij = k · (M_i · M_j)^a / d_ij^θ, где M — пассажиропоток аэропорта (население проверили — оно не объясняет поток), d — расстояние.
   Коэффициенты подобраны по реальным рейсам **всех перевозчиков** на табло 16 аэропортов (590 строк, неделя 10–16.11.2026) с поправкой на транзит в хабе S7 (Толмачёво). Проверка на отложенных парах, которые модель не видела.
2. **Как поедет пассажир — логит-модель выбора** (McFadden): прямой рейс каждого перевозчика, пересадка в Москве, пересадка в Екатеринбурге или Самаре, доехать до соседнего аэропорта, поезд (факт РЖД), машина/автобус.
   U = β_t·часы + β_x·пересадки + β_f·ln(рейсов в неделю) + β_p·цена. Веса времени и пересадки — из исследования бронирований (Coldren, Koppelman), β_f = 1,35 (S-кривая доли рынка), β_p = β_t / 750 ₽/ч (стоимость часа по методике Минтранса). Константы поезда и машины подобраны по факту.
   **Точность:** на 59 реальных рейсах корреляция 0,84, медианная погрешность 33%.
3. **Сценарии при равном флоте:** хаб в Самаре / прямые рейсы / гибрид. Один и тот же алгоритм раскладывает N новых SJ-100 (4 — базовый, 2 — осторожный) на самые прибыльные рейсы. Учтены: вместимость (загрузка ≤ 85%), перегоны к рейсам вне баз (базы — Домодедово, Жуковский, Кольцово), постоянные расходы базы хаба (118 млн ₽/год), закрытия аэропорта, субсидии ПП № 1242.
   Прибыль = выручка − блок-часы × 600 тыс. ₽ − база + субсидии. Флот = блок-часы / (6,3 ч/сут × 365).
   Эффект для страны: сэкономленные пассажиро-часы, индекс доступности городов (Хансен), число пар городов, связанных без Москвы.
4. **Устойчивость вывода:** 23 проверки по одному допущению (спрос ±20%, тариф −15/+10%, стоимость часа, субсидии, закрытия Самары 0–10%, стоимость базы 45–231 млн) и Монте-Карло — 500 случайных наборов всех допущений сразу.

**Факт / допущение / оценка** помечены в каждой таблице; для каждого маршрута А→Б указан источник частоты и метод оценки пассажиропотока (`results/routes_table.csv`).
