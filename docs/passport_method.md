# Метод (подробно)

**Как считали.** Модель — цепочка из четырёх шагов на Python, все допущения в одном файле параметров (`model/params.py`, у каждого — источник или пометка «допущение»), расчёт повторяется одной командой (`python model/run_all.py`).

1. **Спрос между городами — гравитационная модель** (стандарт транспортного планирования):
   T_ij = k · (M_i · M_j)^a / d_ij^θ, где M — пассажиропоток аэропорта (население проверили — оно не объясняет поток), d — расстояние.
   Коэффициенты подобраны МНК по 179 парам с фактическими рейсами **всех перевозчиков** на табло 40 аэропортов (ноябрь 2026) с поправками на транзит в хабе S7 (Толмачёво) и на вахтовые города. Проверка на отложенных парах, которые модель не видела.
2. **Как поедет пассажир — логит-модель выбора** (McFadden): прямой рейс каждого перевозчика, пересадка в Москве, в Екатеринбурге или новом хабе, доехать до соседнего аэропорта (не дальше 250 км по дороге; Сочи — с крюком ×1,6 из-за гор), поезд (факт РЖД), машина/автобус.
   U = β_t·часы + β_x·пересадки + β_f·ln(рейсов в неделю) + β_p·цена. Веса времени и пересадки — из исследования бронирований (Coldren, Koppelman), β_f = 1,35, β_p = β_t / 750 ₽/ч (стоимость часа по методике Минтранса). Константы поезда и машины подобраны по факту.
   **Точность:** на 179 реальных рейсах корреляция (в логарифмах) 0,52, половина рейсов — в пределах ±2 раз.
3. **Поправка на пары без рейсов.** Калибровка идёт только по парам, где рейсы есть, поэтому на новых парах модель завышает спрос. Проверка на трёх реальных запусках 2021–2023 (Челябинск–Уфа, –Самара, –Тюмень; раз в неделю, с субсидией; все сняты): без поправки модель давала им загрузку 194%, 327% и 83%. Спрос новых пар ×0,3 (нужно 0,18–0,7), новые пары короче 500 км — не чаще 3 рейсов в неделю. Проверки: ×0,5 и ×1,0.
4. **Сценарии при равном флоте:** хаб (основной кандидат — Уфа; Самара, Казань, Волгоград, Омск — в сравнении) / прямые рейсы / гибрид. Один и тот же жадный алгоритм раскладывает N новых SJ-100 (4 — базовый, 2 — осторожный) на самые прибыльные рейсы на блок-час и выбирает лучший момент остановки. Учтены: вместимость (загрузка ≤ 85%), перегоны к рейсам вне баз (базы — Домодедово, Жуковский, Кольцово), постоянные расходы базы хаба (118 млн ₽/год), фактические закрытия аэропорта хаба (samokatus.ru, 90 дней), субсидии ПП № 1242 (30 недель в году).
   Прибыль = выручка − блок-часы × 600 тыс. ₽ − база + субсидии. Флот = блок-часы / (6,3 ч/сут × 365).
   Выручка = минимальный тариф АТОР × коэффициент выручки Red Wings (базовый 1,15 — уровень «Азимута»; проверяем 1,0–1,6). Это неопределённость текущего уровня выручки, а не повышение цен, поэтому спрос не меняется.
   Эффект для страны: индекс доступности городов (Хансен, логсумма), число пар городов, связанных без Москвы, доля рынка.
5. **Устойчивость вывода:** 28 проверок по одному допущению (спрос ±20%, тариф −15/+10%, стоимость часа, субсидии, перегоны, стоимость базы 45–231 млн, спрос новых пар, поездки до соседнего аэропорта, закрытия хаба 2–10%) и Монте-Карло — 500 случайных наборов всех допущений сразу. Пороги окупаемости — по выручке и стоимости блок-часа. Город хаба — расчётом для пяти кандидатов из рейтинга, с долей стыковочных пассажиров и проверкой «хаб без маршрутов конкурента».

**Факт / допущение / оценка** помечены в каждой таблице; для каждого маршрута А→Б указан источник частоты и метод оценки пассажиропотока (`results/routes_table.csv`).
